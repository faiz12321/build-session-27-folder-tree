How to see the shape of a folder at a glance

Short answer

A folder can hide files several levels down. This lesson builds a small read-only Python tool that prints a folder as an indented tree: each level inwards adds two spaces, folder names end with a slash, and names are sorted letter by letter, ignoring letter case. The tool has no code that changes, moves or deletes anything, and it shows names only, never what is inside files.

Follow along and build it step by step. You add each file yourself, run each command, and see the real recorded result.

Common mistakes

  1. Reading only the top level. A flat list of one folder tells you nothing about what its subfolders hold, and a folder looks just like a file in it.
  2. Trusting the tree as complete. Folders the tool cannot read are skipped. The tree only shows what the tool could see.
  3. Expecting file details from a tree. The report is names and shape only. It says nothing about sizes, times or contents.

Frequently asked questions

What does the indentation mean?

Two spaces per level inwards. A line under photos/ and indented once sits directly inside photos; indented twice, it is one folder deeper.

Why do folder names end with a slash?

So a folder is never mistaken for a file in the report.

Will this change or delete anything?

The checker reads only. The separate setup creates a new fictional sample and refuses any existing sample path. Tests check selected fixture bytes and metadata, not every real-world case.

How is this different from the tree command on Windows?

The idea is the same: Windows has a built-in tree command that draws a folder's shape. This lesson builds your own small version in Python, so you can see how such a tool works and change it.

Does it read my files?

No. It asks the system for names only and never opens a file.
